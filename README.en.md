# Russian Metro Addon

[简体中文](./README.md) · English

Adds Russian metro-themed transport resources and station decoration for existing lines or new MTR stations.

## Download and installation

- Version · [v2.0.0-port.1+26.3](https://github.com/OpenRongMC/Russian-Metro/releases/tag/v2.0.0-port.1%2B26.3) (Release)
- Release asset · `rongmc-russianmetro-2.0.0-port.1.26.3.jar`
- Runtime · Minecraft Java 26.3, Fabric, Java 25
- Fabric Loader · `>=0.19.3`
- Fabric mod ID · `rongmc_russianmetro`
- Dependencies declared by the JAR · [Fabric API](https://modrinth.com/mod/fabric-api), [`rongmc_mtr`](https://github.com/OpenRongMC/Minecraft-Transit-Railway) `4.0.5-port.1+26.3`

Place the release JAR in the instance’s `mods/` directory. Install the matching RongMC MTR and this addon on both sides. Resource-pack overrides can change train models or textures, so record pack order when troubleshooting.

## How to try it

Run a consist using one of the addon vehicles and check the train and station decorations from the client. Preserve the resource packs and vehicle IDs when trying an existing world.

## Development

Develop and test alongside the matching MTR and platform mappings. The RongMC transport build uses Java 25. Use the coordinated workspace and release metadata when reproducing a release.
