# 俄罗斯地铁扩展

简体中文 · [English](./README.en.md)


俄罗斯地铁扩展由 WerySkok 开发，收录莫斯科地铁新旧闸机、售票机、Info-SOS 求助立柱、地铁标识和首车停车标志，也包括圣彼得堡地铁的「水平电梯」式站台门。

## RongMC 26.3 版本的改动

本版适配 Minecraft 26.3 的方块、物品或列车资源加载，并改用配套 MTR 4.0.5 的接口。扩展已有的主题和玩法沿用上游。

## 安装

在 [GitHub Releases](https://github.com/OpenRongMC/Russian-Metro/releases/tag/v2.0.0-port.1%2B26.3) 下载 **v2.0.0-port.1+26.3**。使用 Minecraft Java **26.3**、**Fabric** 和 **Java 25**。 依赖 [Fabric API](https://modrinth.com/mod/fabric-api)、[MTR](https://github.com/OpenRongMC/Minecraft-Transit-Railway)。 将发行 JAR 放进实例的 `mods/` 目录。 在双端安装同系列 RongMC MTR 与此扩展。资源包覆盖可能改变列车模型或贴图，排查时先记录资源包顺序。
