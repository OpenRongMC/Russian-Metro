# 俄罗斯地铁扩展

简体中文 · [English](./README.en.md)

为 MTR 增加俄罗斯地铁风格的交通资源和车站装饰，可用于已有线路和新建站点。

## 下载与安装

- 版本 · [v2.0.0-port.1+26.3](https://github.com/OpenRongMC/Russian-Metro/releases/tag/v2.0.0-port.1%2B26.3) (已发布)
- 下载文件 · `rongmc-russianmetro-2.0.0-port.1.26.3.jar`
- 运行环境 · Minecraft Java 26.3, Fabric, Java 25
- Fabric Loader · `>=0.19.3`
- Fabric 模组 ID · `rongmc_russianmetro`
- JAR 声明的依赖 · [Fabric API](https://modrinth.com/mod/fabric-api), [`rongmc_mtr`](https://github.com/OpenRongMC/Minecraft-Transit-Railway) `4.0.5-port.1+26.3`

把发行 JAR 放入对应实例的 `mods/` 目录。在双端安装同系列 RongMC MTR 与此扩展。资源包覆盖可能改变列车模型或贴图，排查时先记录资源包顺序。

## 如何验证

创建一个包含扩展车辆的侧线编组并开行，再从客户端检查车辆与站内装饰。升级旧图时先保留原有资源包和车辆 ID。

## 开发

与同一版本的 MTR 和平台映射一起联调。交通套件的 RongMC 发布构建使用 Java 25，应以配套工作区和发行 JAR 的元数据为准。
