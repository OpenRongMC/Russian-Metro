# Russian Metro Addon

[简体中文](./README.md) · English


The Russian Metro addon by WerySkok includes old and new Moscow fare gates, ticket machines, Info-SOS stands, metro emblems and first-car stop markers. It also includes St. Petersburg-style “horizontal elevator” platform doors.

## What changed in the RongMC 26.3 port

The port adapts block, item or vehicle-resource loading for Minecraft 26.3 and uses the matching MTR 4.0.5 interfaces. The addon retains its upstream theme and gameplay.

## Installation

Download **v2.0.0-port.1+26.3** from [GitHub Releases](https://github.com/OpenRongMC/Russian-Metro/releases/tag/v2.0.0-port.1%2B26.3) for Minecraft Java **26.3** on **Fabric** with **Java 25**. Dependencies include [Fabric API](https://modrinth.com/mod/fabric-api), [MTR](https://github.com/OpenRongMC/Minecraft-Transit-Railway). Place the release JAR in the instance’s `mods/` directory. Install the matching RongMC MTR and this addon on both sides. Resource-pack overrides can change train models or textures, so record pack order when troubleshooting.
