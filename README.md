# MTR Russian Metro Addon

A Russian Metro Addon for the [Minecraft Transit Railway](https://github.com/jonafanho/Minecraft-Transit-Railway) mod (original author: WerySkok).

Adds Russian metro themed trains, stations and decorations for MTR.

---

## RongMC · Minecraft 26.3 Fabric 移植说明

本仓库是 RongMC 维护的 **Minecraft 26.3 / Fabric / Java 25** 移植构建，不是上游官方发行渠道。

### 与原版的主要差异
- Minecraft 26.3 Fabric 移植；Fabric id `rongmc_russianmetro`（provides `russianmetro`）。
- 依赖 `rongmc_mtr`。

### 已知问题 / 限制
- 上游缺少完整 README；本说明按 fabric.mod.json 与移植实践整理。
- 附属内容依赖 MTR 数据包/列车系统；核心损坏时本模组也会表现为“不工作”。

### 构建与安装
- Fabric mod id：`rongmc_russianmetro`（`provides`：`russianmetro`，旧依赖名一般仍可解析）
- Release 产物见本仓库 Releases（jar 名带 `rongmc-` 前缀）
- 许可证：本仓以 **GPL-3.0** 发布（见 `LICENSE`）；请同时尊重上游原作者条款与署名
